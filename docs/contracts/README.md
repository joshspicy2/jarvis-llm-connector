# Contract templates

Placeholder templates for the five contract types in `docs/design/billing-and-contracts.md`. Each file name is the template id used by n8n.

All wording is `REPLACE_WITH_*` until Makenzie/Joshua supply it. Do not invent legal terms or prices; prices and discounts come from Estimate Rules in Notion. Bump the `Version` line whenever the text changes so signed copies can reference the exact version.
